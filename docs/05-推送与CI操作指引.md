| 字段 | 填什么 |

| Initialize this repository with | **全部不勾**（README / .gitignore / license 都不要） |

点 **Create repository**。

### 第 2 步 · 推送

建完后 GitHub 会显示一段命令。**别用它的**，用下面这段（本仓库已有提交）：

```bash
cd "C:/Users/14256/Desktop/newM/EarTimer"

git remote add origin https://github.com/<你的用户名>/EarTimer.git
git push -u origin main
```

把 `<你的用户名>` 换成你的 GitHub 用户名。

> 第一次 push 会弹浏览器让你登录 GitHub。登录完就好，之后不用再登。

### 第 3 步 · 等它跑完

推送成功后打开：

```
https://github.com/<你的用户名>/EarTimer/actions
```

会看到一个叫 **Build iOS** 的任务在跑，大约 3–5 分钟。

### 第 4 步 · 下载 .ipa

## 两种结果，分别怎么办

### 情况一：绿色 ✓

**说明代码能编译。** 这是我最没底的部分，现在被验证了。

拿到 `.ipa` 后要装到手机，它还没签名，需要：

| 工具 | 平台 | 说明 |
|---|---|---|
| **Sideloadly** | Windows ✅ | 手机连电脑，输入 Apple ID，自动签名安装 |
| **AltStore** | Windows | 需要装 AltServer |
| **TrollStore** | — | 仅特定 iOS 版本（14.0–16.6.1 等），永久免签 |

免费 Apple ID 签的包 **7 天过期**，Sideloadly 可以后台自动续签。

### 情况二：红色 ✗

点进失败的那一步，找到 `================ 错误 ================` 那段。

**把那段文字贴给我**，我按错误改。工作流已经做了这两件事，你不用自己翻日志：

```bash
grep -E "error:" build.log | head -60    # 只挑错误行
tail -80 build.log                       # 末尾上下文
```

也可以直接下载 `build-log` artifact 把 `build.log` 发我。

## 我预判的几个可能报错

按可能性排序：

| 报错关键词 | 原因 | 怎么改 |
|---|---|---|
| `Cannot find 'X' in scope` | `Shared/` 没被编进某个 target | 检查 `project.yml` 的 `sources` |
| `@Model` / `#Predicate` 相关 | SwiftData 宏在 Swift 6 下的限制 | 可能要加 `@available` 或调整 Predicate 写法 |
| `Main actor-isolated ... cannot be referenced` | Swift 6 严格并发 | 加 `@MainActor` 或改 `nonisolated` |
| `No such module 'X'` | 缺 framework 链接 | 在 `project.yml` 加 `dependencies` |
| `Multiple commands produce` | Widget 和主 App 重复编译同一文件 | 检查 `Shared/` 是否被两边都加进去（**这是预期的**，两边都需要） |
| `Signing for "EarTimer" requires a development team` | 签名没禁干净 | 工作流已用 env + 行内双重禁用，应该不会出现 |

## 常见疑问

**Q：私有仓库行不行？**
行，但 Actions 要计费：私有仓库每月 2000 分钟，**macOS 按 10 倍算 = 200 分钟**。编译一次约 4 分钟 = 40 分钟额度，够跑 5 次。公开仓库无限免费。

**Q：会泄露代码吗？**
公开仓库任何人都能看到源码。不想公开就把仓库设私有，或用 `git push` 到私有仓库后再改可见性。

**Q：改了代码要重新跑吗？**
每次 `git push` 到 `main` 会自动触发。也可以在 Actions 页面点 **Run workflow** 手动跑。

**Q：能不能直接出可安装的 .ipa？**
不能。签名需要你的开发者证书，证书不能放进公开仓库。CI 只能出**未签名**包，签名在本地用 Sideloadly 做。

**Q：以后想上架 App Store？**
那必须有付费开发者账号（$99/年）+ 真实 Mac 生成证书。CI 能编译，但上传 App Store Connect 需要 App Store Connect API Key，那是另一套配置。
